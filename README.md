🚌 Bus Ticket Booking Web Application – MERN

This is a full-stack MERN (MongoDB, Express, React, Node.js) project for online bus ticket reservation.
Users can search buses, select seats, and complete booking using a simple GPay/manual payment option.

🌟 Features

✔ User Signup / Login
✔ Search buses based on route and date
✔ Seat selection with real-time availability
✔ Online payment using GPay/manual entry (UPI)
✔ Booking confirmation page
✔ Booking history stored in database
✔ Admin — Add/Update/Delete bus details

🛠️ Tech Stack
Layer	Technology
Frontend	React, HTML, CSS
Backend	Node.js, Express.js
Database	MongoDB localhost
Auth	JWT
Payment	UPI / GPay manual payment
